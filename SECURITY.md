# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository or associated deployments, please report it responsibly:

1. **Email:** Send details directly to `sailikhithcse@gmail.com` with the subject `[SECURITY] Vulnerability Report`.
2. **Details:** Include a clear description of the issue, reproduction steps, and potential impact.
3. **Response SLA:** You will receive an initial response within 24 hours acknowledging receipt and an estimated remediation timeline.
